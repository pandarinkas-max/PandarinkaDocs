# Uncensor Search

<div class="guide-image">
  <img src="assets/images/uncensor-search.png" alt="Uncensor Search window">
</div>

**Uncensor Search** helps you find and switch character uncensors faster.

Use it when the uncensor list is long and you do not want to scroll through every entry manually.

## Quick Start

1. Open **Pandarinka Toolkit**.
2. Go to **Characters**.
3. Open **Uncensor Search**.
4. Select the character you want to change.
5. Type part of the uncensor name in the search field.
6. Pick the uncensor from the filtered list.

The selected uncensor is applied to the character.

## Notes

- Search is useful when you have many uncensors installed.
- If an uncensor does not appear, check that it is installed correctly and available for the selected character.
