# Uncensor Search

<div class="guide-image">
  <img src="assets/images/uncensor-search.png" alt="Uncensor Search window">
</div>

**Uncensor Search** helps you find and switch character uncensors faster.

Use it when the uncensor list is long and you do not want to scroll through every entry manually.

## What It Shows

- The uncensor name.
- The zipmod or source name.
- The currently selected uncensor.
- An **Open** button for the related source folder or zipmod file when it can be found.

This makes it easier to understand which uncensor is installed from which mod, especially when several uncensors have similar names.

## Notes

- Click an uncensor name to apply it to the selected character.
- Use the search field when you only remember part of the uncensor name or zipmod name.
- If **Open** is disabled, the plugin could not find the source file path for that entry.
