# Folder Scale

**Folder Scale** lets Studio folders scale their contents from the normal scale gizmo.

Use it when you have a group of objects inside one folder and want to resize the whole group faster.

## Quick Start

1. Open **Pandarinka Toolkit**.
2. Go to **Transform**.
3. Open **Folder Scale**.
4. Turn on **Enable Folder Scale**.
5. Select a Studio folder.
6. Use the normal Studio scale gizmo.

## Modes

**Folder Scale** can work in two ways:

- **Whole folder group**: scales the folder contents together as one group.
- **Items individually**: uses the folder scale gizmo as input, but applies scale to each child item around its own pivot.

Use **Refresh Folders** if you added or changed folders and the tool does not see them yet.

## Notes

- This is useful for map parts, extracted folders, and environment setups.
- If the result looks wrong, try switching the individual-items mode and scale again.
- Folder Scale is in **Transform**, not in the Environment tab, but it is useful together with Environment tools.
