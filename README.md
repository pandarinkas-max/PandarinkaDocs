# Pandarinka Docs

Guides for Pandarinka Studio tools.

## Current Guides

- [Pandarinka Toolkit](pandarinka-toolkit.md) · [Patreon](https://www.patreon.com/Pandarinka/posts/pandarinka-and-154581882) - Studio utility plugin with multiple tools in one window.
  - [Soft Body](soft-body.md) - paint and shape characters, clothing, and objects; combine raised and recessed areas on snow fields.
  - [Jiggle Dynamics](jiggle-dynamics.md) - make selected bones react to character or object contact.
  - [Environment](environment.md) - create snowy or rainy scenes with snow fields, object snow, character snow, falling snow, blizzard effects, and rain.
  - [Clothing Lab](clothing-lab.md) - unlocks all clothing slots and the complete female clothing library for male characters in Studio Character Editor.
  - <a class="program-link" href="#/pose-match">PoseMatch Program</a> - desktop program for creating pose drafts from reference images.
  - [Pose Match](pose-match.md) - apply pose drafts to selected Studio characters.
  - [SliceWorks](sliceworks.md) - cut characters and objects, create holes, and add blood effects.
  - [Neck Seam](neck-seam.md) - blend the join between head and body skin and soften harsh shadows under the chin.
  - [Seamless Dick](seamless.md) - smooth the visual transition between a penis and character skin with a shader-based seam blend.
  - [RigFlow](rigflow.md) - make character posing and animation easier with combined IK/FK controls and adjustable movement smoothing.
  - [Uncensor Search](uncensor-search.md) - find and switch character uncensors faster.
  - [Copy Pose From](copy-pose-from.md) - copy FK or IK poses from another character.
  - [Joint Follow](joint-follow.md) - keep IK elbows and knees aligned while moving hands or feet.
  - [Folder Scale](folder-scale.md) - scale Studio folders and their contents from the Transform tab.
  - [IK for Objects](ik-for-objects.md) - add IK controls to NPCs with FK bones, including tails and tentacles.
  - [Navigator for Objects](navigator-for-objects.md) - guide connected FK bones with Classic controls or move flexible objects along editable curved paths, with Timeline progress control.
  - [Refer To Animation](refer-to-animation.md) - move object FK points to the current animation pose.
  - [Drop to Surface](drop-to-surface.md) - drop selected objects onto the nearest surface below.
  - [Keep Texture Scale](keep-texture-scale.md) - keep texture tiling consistent while objects are scaled.
  - [Scatter Objects](scatter-objects.md) - duplicate objects across an area or surface.
  - [Bake to Mesh](bake-to-mesh.md) - combine a generated folder into a baked mesh object.
  - [Options](toolkit-options.md) - hotkeys, window size, position, and opacity.
- [Quick Pick](quick-pick.md) · [Patreon](https://www.patreon.com/Pandarinka/posts/quickpick-plugin-152601223) - select Studio objects and characters from the viewport, extract map objects, cache assets, and cache full maps.
- [Studio FBX Exporter](fbx-exporter.md) · [Patreon](https://www.patreon.com/Pandarinka/posts/studio-fbx-154930351) - export selected Studio objects or characters to FBX with textures.
- [Scene Browser Pro](scene-browser-pro.md) · [Patreon](https://www.patreon.com/Pandarinka/posts/scene-browser-152470123) - manage scene saves, save selected parts separately, and import only what you need.
- [Recycle Bin](recycle-bin.md) · [Patreon](https://www.patreon.com/Pandarinka/posts/recycle-bin-153543777) - restore deleted objects or stash scene parts for later.
