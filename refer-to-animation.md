# Refer To Animation

  <img src="assets/images/refer-to-animation.gif" alt="Refer To Animation preview">
</div>

**Refer To Animation** lets one character use another character's animation as a reference.

Use it when you already have an animated character and want another character to follow that motion faster, without rebuilding the animation by hand.

## Quick Start

1. Open **Pandarinka Toolkit**.
2. Go to **Characters**.
3. Open **Refer To Animation**.
4. Choose the character that should use the reference.
5. Choose the character that already has the animation.
6. Apply the reference.

After that, check the result in the timeline or animation playback and adjust the pose if needed.

## Notes

- This is useful for quickly matching animation between characters.
- The reference character should already have the animation you want to use.
- If the result looks wrong, check that the correct source and target characters are selected.
